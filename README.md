# Антидеградация

Личная система против слива жизни: цели → план → сегодняшний минимум → действие → анализ.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

### Доступ с iPhone (одна Wi-Fi сеть)

```bash
npm run dev
# или явно:
npx vite --host 0.0.0.0
```

1. Mac и iPhone в одной Wi-Fi сети.
2. Узнать IP Mac: `ipconfig getifaddr en0` (или `hostname -I` на Linux).
3. На iPhone в Safari открыть `http://192.168.X.X:5173`
4. Поделиться → На экран «Домой» — приложение установится как PWA.

## Возможности (MVP)

- ✅ Онбординг
- ✅ Главный экран «Сегодня» с состоянием дня и следующим действием
- ✅ Правило «НЕ НОЛЬ» — минимальные версии задач
- ✅ Режим «Я деградирую» (антидеградация)
- ✅ Кнопка «Я сорвался» + восстановление
- ✅ Focus Timer (10/15/25/45/60 мин)
- ✅ Большие цели с полем «Зачем?»
- ✅ Планирование дня + «Сформировать мой день»
- ✅ Правило 3 главных дел
- ✅ Вечерний отчёт
- ✅ Статистика + DAYS WITHOUT ZERO
- ✅ Серия с мягким восстановлением
- ✅ Помощник (сценарии: лень, прокрастинация, перегруз, срыв, грусть)
- ✅ Экспорт / импорт JSON
- ✅ Полностью локально (LocalStorage)
- ✅ PWA (manifest + service worker)
- ✅ Mobile-first, safe-area, тёмная тема

## Стек

React + TypeScript + Vite + Tailwind CSS + Lucide + date-fns + uuid

Данные хранятся только на устройстве. Backend не требуется.
